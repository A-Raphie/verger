# Verger design.md

## Style Genome
- Mode: C (warm editorial) one level deep with D (paper desk) hairline + tabular discipline. Espresso action swapped for AWS smile-orange #fa6f00 (mined from a0.awsstatic.com live CSS Sep 9; sponsor-token rule).
- Axis pushes: editorial serif display (Fraunces, parish voice) · warm paper + single filled sponsor accent (village-hall, not fintech) · scarcity-event motion (bell + receipt ticks only; the promise is silence)
- Axes conventional: hairline-only elevation, editorial whitespace, centered one-column fold
- Neutral reference: coss.com/ui (standing light-first binding, verified live this build)
- Signature move: THE DECISION BELL. Rings (one swing, once per new pending decision) only when the agent is holding a real judgment call for the trustee. A silent week is the success state. Bespoke; never harvested.
- Ledger check: tally (terminal instrument, dark) · tally v3 (indigo on dark) · lading (light split planes, faithfulness diff). Verger differs on color (warm paper vs dark/neutral), type (serif vs mono/grotesk), motion (scarcity events vs stillness/live-diff), layout (centered fold vs split).
- Clone test: warm paper + serif + orange ledger is not coss's white neutral sans grammar.

## Avoid-list
Dark dashboards, glassmorphism, bento grids, purple/blue gradients, emoji icons, stock photos, document/ledger layout metaphor (owned by prior builds), stamp strikes (assay), mono-first (rushes/tally), stillness-as-pitch, desaturated verdict pairs, floating hero numbers, dead links.

## Folds used
- Front door: chose centered one-column hero + ONE framed live panel below the CTAs (the landed grammar); sacrificed the split-hero live rail (drift toward remlo control room) and a full-bleed before/after canvas (too heavy for first paint).
- Desk: chose single narrative column (porch → the week → ledger, reads like the trustee's morning); sacrificed the sticky two-column porch rail (breaks the centered-fold genome) and tabs (hides the ledger behind a click during the demo).
