But look: the send is a tool call, and a hook in the Strands agent stops it cold with an interrupt. The bell rings once. The reply waits on the porch, and nothing moves until I decide. The whole round runs in small steps on a serverless function, and the agent's memory survives between them, so it can pause for hours and pick up exactly where it stopped.

Underneath, the receipts. Every read, every draft, every hold, written to a hash chain: each row signed against the one before it. The badge says verified because the agent checks its own chain again on every write. This page never computes it. The agent does.

The receipt lands on the chain before the button stops glowing. Watch the numbers: answered ticks up by one, waiting drops, and the ledger grows. And if I had said no, the draft would be dead, right here, on the record.
